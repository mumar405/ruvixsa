      Robots.txt and meta robots: what is the difference?
      A robots.txt file controls which paths crawlers may request. A meta robots tag or an X-Robots-Tag header controls what a search engine may do with a page it has already crawled, such as indexing it or showing a snippet.
      The two work together but do different jobs. To keep a page out of search results, use noindex, and make sure robots.txt does not block that page, because a crawler cannot read a noindex tag on a page it is not allowed to open.

      Robots.txt syntax cheat sheet
      RuleWhat it does
      User-agent: *Starts a group of rules for all crawlers.
      Disallow: /private/Blocks every path that starts with /private/.
      Allow: /private/help/Makes an exception inside a blocked folder.
      Disallow: /*.pdf$Blocks URLs that end in .pdf. The * matches any characters and $ marks the end.
      Sitemap: https://example.com/sitemap.xmlTells crawlers where your sitemap is.
      Paths are case sensitive. The longest matching rule wins, and Allow wins a tie.
      

      Frequently asked questions
      What is a robots.txt file?
      It is a plain text file at the root of your website that tells crawlers which paths they may or may not request. Well-behaved crawlers such as Googlebot and Bingbot follow it. It is a request, not a security control.
      Does Disallow remove a page from Google?
      No. Disallow stops crawling, not indexing. A blocked page can still appear in search results if other pages link to it. To keep a page out of search results, use a noindex meta tag or an X-Robots-Tag header, and do not block that page in robots.txt, because crawlers must be able to read the tag.
      Where do I put the robots.txt file?
      At the root of the host, for example https://example.com/robots.txt. Each subdomain needs its own file. In Blogger you can add custom robots.txt text in the settings, and in WordPress an SEO plugin or a file in the site root does the job. Menu names can differ, so check your platform.
      How does Google choose between Allow and Disallow?
      The most specific rule wins, which means the one with the longest matching path. If an Allow and a Disallow match with the same length, Google uses the less restrictive one, which is Allow.
      Should I block AI crawlers?
      It is your choice. Training crawlers such as GPTBot and ClaudeBot are separate from search bots such as OAI-SearchBot and Claude-SearchBot, so you can block one kind and allow the other. Blocking search bots can reduce how often your site appears in those AI search tools. Some user-triggered fetchers may not follow robots.txt at all.
      Can robots.txt hide private pages?
      No. The file is public, and listing a path in it shows that the path exists. Protect private pages with a login or other access control.
      Does this tool read my live robots.txt?
      No. You paste the text yourself. The HTTP status checker asks your browser to request a URL, and many sites do not allow that, so a failed check does not mean the page is down.
      Is my text uploaded or saved?
      No. Everything runs in your browser and nothing you type is sent to Ruvixsa or saved. The status checker sends one request from your browser to the URL you enter.

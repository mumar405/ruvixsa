    What are Open Graph tags?
    Open Graph tags are small pieces of HTML in the head of a page. When someone shares your link on a platform such as Facebook, LinkedIn or WhatsApp, the platform reads these tags to build the preview card: the title, the description and the image. X (Twitter) looks for its own twitter: tags first and can fall back to the Open Graph tags.
    These tags control how a shared link looks. They are not a Google ranking factor, and Google builds its search results from the page title and the meta description.
    

    How to use the Open Graph generator
    1. Enter the page URL, title and description of the page you want to share.
    2. Add a share image address. The tool checks its size and shape.
    3. Check the previews for Facebook, X, LinkedIn and WhatsApp.
    4. Copy the meta tags and paste them inside the head section of your page.
    

    How to add the tags to your site
    • Blogger: go to Theme, then Edit HTML, and paste the tags just below the opening head tag. Tags pasted there apply to every page, so for posts you can use Blogger's dynamic tags instead.
    • WordPress: an SEO plugin such as Yoast SEO or Rank Math usually adds Open Graph tags for you. If you add tags by hand, avoid duplicates.
    • Custom site: paste the tags into the head of each page, or into your shared layout file.
    An example of dynamic tags for Blogger posts (test it after saving):
    <b:if cond='data:view.isPost'>
<meta property='og:title' expr:content='data:blog.pageName'/>
<meta property='og:description' expr:content='data:blog.metaDescription'/>
</b:if>
    After you publish, check a link with the Facebook Sharing Debugger.

    Frequently asked questions
    Why is my link preview not updating after I changed the tags?
    Social platforms store (cache) the preview of a link for a while. To refresh it, paste your URL into the Facebook Sharing Debugger and scrape it again, or use the LinkedIn Post Inspector. Other platforms, such as WhatsApp, give you no tool, so the old preview can stay for some time.
    Why does WhatsApp show no image?
    Common causes are an image that is too large, an address that is not https, an image behind a redirect, or missing og:image tags. WhatsApp does not publish exact limits, but a file size under about 300 KB is often recommended, so keep the image small.
    Do Open Graph tags affect Google rankings?
    No. Google does not use Open Graph tags as a ranking factor. Its search results use the page title and the meta description. Open Graph tags control how your link looks when someone shares it, and a clear preview can make people more willing to click.
    Do AI search tools use Open Graph tags?
    There is no confirmed rule that AI answer tools use Open Graph tags to choose what they quote. Treat these tags as link preview tools, and do not expect them to change how AI tools mention your site.
    What is the difference between og:image and twitter:image?
    og:image is part of the Open Graph protocol, which Facebook, LinkedIn, WhatsApp and many other apps read. twitter:image is the tag X (Twitter) looks for first. If the Twitter tags are missing, X can fall back to the Open Graph tags, but setting both is the safest choice.
    Which image format should I use?
    JPG and PNG are the safest choices because every platform reads them. WebP works in many places but not everywhere. Use an https address, a direct link to the image, and a file that is not too large.
    Is my data uploaded or saved?
    No. The tags and previews are made in your browser and nothing you type is sent to Ruvixsa. If you enter an image address, your browser requests that image from its host so the preview can show it.
    What does og:type mean?
    It tells platforms what kind of page you are sharing. Use website for home pages, tools and landing pages, and article for blog posts and news stories.

What is image compression?

Image compression makes an image file smaller. Smaller files use less storage, are easier to share and help pages load faster. Compression can remove some detail, so it is worth checking the result before you use it.

This tool compresses in your browser. You see the original and the compressed image side by side, with the size saved, and you can change the quality, the format and the maximum width until you are happy.

How to use the image compressor

  1. Choose an image (JPG, PNG or WEBP, up to 10 MB).
  2. Look at the result. The image is compressed straight away and shown next to the original.
  3. Adjust it. Move the quality slider, pick a format or set a smaller maximum width.
  4. Download the compressed image.

Tips for smaller images

  • Reduce the width first. An image shown at 800 px wide does not need 4000 px.
  • Use JPG or WEBP for photos.
  • Try quality 70 to 85, then check the preview for blur or blocky areas.
  • Keep your original file. Compressing again and again lowers quality each time.

Frequently asked questions

Is my image uploaded to a server?

No. The image is compressed in your browser and is never sent to Ruvixsa. Nothing is saved, and when you close the page the image is gone.

Which format gives the smallest file?

For photos, JPG or WEBP usually give a smaller file than PNG. PNG is lossless and best for logos, screenshots and images with transparency, but the file can be larger. WEBP is often smaller than JPG, but some older browsers cannot create it.

Why did my PNG get bigger, or not smaller?

PNG is lossless, so the quality slider does not change a PNG file. To make the file smaller, choose JPG or WEBP, or reduce the maximum width.

What does the quality slider do?

For JPG and WEBP it sets how much detail is kept. A lower number gives a smaller file and more visible compression. Values between 70 and 85 often look fine for photos, but always check the preview.

Does it keep transparent areas?

PNG and WEBP keep transparency. JPG cannot, so transparent areas become white.

Why did I get a PNG when I chose WEBP?

Some browsers cannot create WEBP files. When that happens the tool makes a PNG instead and tells you so.

Does it change the size of my image?

Only if you pick a smaller maximum width. Otherwise the width and height stay the same. Because the image is drawn again, details such as camera and location data are not kept in the new file.

Are there any limits?

You can use JPG, PNG or WEBP files up to 10 MB. Very large images of about 40 megapixels or more may not work on some phones.

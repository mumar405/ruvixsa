What is schema markup?

Schema markup is structured data, usually written as JSON-LD, that describes what a web page is about in a format search engines can read. It uses the Schema.org vocabulary to label things such as articles, products, organizations and questions, and it does not change how your page looks.

It helps search engines understand a page and can make it eligible for some rich results. It does not guarantee rankings, rich results or mentions in AI answers.

How to use this schema markup generator

  1. Choose your platform: WordPress, Shopify, Blogger or a custom website. This tailors the paste instructions.
  2. Pick Single Schema or Multiple Schema, then choose the schema type you need.
  3. Fill in only the fields that are true for your page. Empty optional fields are left out.
  4. Generate, copy the JSON-LD, paste it into your page, and test it with a validator.

Supported schema types

Article, Product, WebSite, WebPage, Organization, FAQPage, BreadcrumbList, VideoObject, LocalBusiness, Review, Recipe and SoftwareApplication.

Single or multiple? Single Schema creates one schema type for one page, such as an Article. Multiple Schema lets you add several types, such as Article, BreadcrumbList and FAQPage, and combines them into one JSON-LD block using @graph.

Where do I paste the JSON-LD?

  • WordPress: add it to your page head with an SEO or header-and-footer plugin, or place it in the page content with a Custom HTML block.
  • Shopify: open Online Store, Themes, Edit code, then paste it before the closing head tag in theme.liquid.
  • Blogger: go to Theme, Edit HTML, and paste it before the closing head tag.
  • Custom website: paste it inside a script tag of type application/ld+json in your page head.

Frequently asked questions

Is this schema markup generator free?

Yes. The tool is free to use, and the code is generated in your browser from the details you enter.

What is JSON-LD?

JSON-LD is a way of writing structured data as a small block of code. It is the format Google recommends for structured data, and you paste it into your page without changing what visitors see.

Does schema markup improve rankings?

Schema markup is not a ranking guarantee. It helps search engines understand your content and can make a page eligible for some rich results when the markup matches the visible page.

Does FAQ schema still show rich results in Google?

No. Google stopped showing FAQ rich results in Search on 7 May 2026. FAQPage is still a valid Schema.org type and the markup can stay on a page, but you should not expect FAQ dropdowns in search results.

Does schema help my site appear in AI answers?

Google says no special markup is required for its AI features, and no search engine promises citations for adding schema. Clear, accurate, visible content matters most. Schema can still describe what a page is and who published it.

Which schema type should I use?

Use Article for blog posts, Product for items you sell, Organization for your brand, and BreadcrumbList for a visible navigation trail. Only add a type when it matches content that is actually on the page.

How do I test my schema?

Paste your code into the Schema Markup Validator at validator.schema.org. For types that Google supports, you can also use Google's Rich Results Test. Test your schema before publishing it.

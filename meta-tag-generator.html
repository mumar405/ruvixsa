What is a meta tag generator?

Meta tags are small pieces of HTML in the head of a page. The title tag and the meta description tell search engines and people what the page is about, and Open Graph and Twitter tags control how a link looks when it is shared on social platforms. This tool helps you write them, check them and copy clean code.

Meta tags do not guarantee rankings. A clear title helps search engines and people understand your page, and the meta description may be shown as the snippet under your result, but Google can rewrite either one.

How to use this meta tag generator

  1. Enter a focus keyword (optional). If you add one, the tool checks whether it appears in your title and description.
  2. Write your meta title and meta description. Watch the character counts and the estimated width under each box.
  3. Add your full page URL starting with https://. It is used for the preview, the canonical tag and og:url. You can also add a social image URL to preview how a shared link may look.
  4. Check the previews and suggestions for Google desktop, Google mobile, Facebook, Twitter and LinkedIn.
  5. Copy the code and paste it into the head of your page.

What this tool checks

  • Title and description length, using the rules of thumb of about 50 to 60 and 130 to 160 characters, plus an estimated pixel width.
  • Whether your focus keyword appears in the title, at the start of the title, and in the description.
  • Repeated words, and whether the description has a call to action.
  • Whether the URL is a full https:// address with a short, readable path.

The Meta Tag Score is a checklist score made by this tool, not a Google score. The length limits and previews are estimates, and Google may show something different.

What code does it generate?

  • The title tag and the meta description.
  • A canonical tag, if you keep that option on and enter a full URL.
  • Open Graph tags: og:title, og:description, og:url, og:image and og:type.
  • Twitter card tags, using a large image card when you add an image.
  • Optional charset and viewport tags.

Only the fields you fill in are included, with no placeholder text. The meta keywords tag is not generated because Google does not use it.

Where do I paste the code?

  • WordPress: use the title and description fields of your SEO plugin, or add extra tags with a header-and-footer plugin.
  • Shopify: use the search engine listing fields of the page, or open Online Store, Themes, Edit code, and paste before the closing head tag in theme.liquid.
  • Blogger: go to Theme, Edit HTML, and paste inside the head.
  • Custom website: paste it inside the head of each page.

If your site already adds some of these tags, do not paste the same tag twice.

Frequently asked questions

Is this meta tag generator free?

Yes. The tool is free to use, and the code is generated in your browser from the details you enter. If you add a social image URL, your browser loads that image so the preview can show it.

What are the meta title and meta description?

The meta title is the page title that browsers and search engines use as the clickable headline. The meta description is a short summary that search engines may use as the snippet under your result.

How long should my title and description be?

There is no official character limit. Search engines cut text by pixel width, so this tool uses common rules of thumb: about 50 to 60 characters for the title and 130 to 160 for the description, plus a rough width estimate. Treat these as guidance, not rules.

Is the Google preview exactly what Google will show?

No. It is an approximation. Google decides what to show for each search and may rewrite your title or description, so the real result can differ.

Do meta tags improve rankings?

They are not a ranking guarantee. A clear title helps search engines and people understand your page. Google says the meta description is not a ranking factor, but it may be used as your snippet and can affect whether people click.

Does Google use the meta keywords tag?

No. Google has said it does not use the meta keywords tag for ranking, so this tool does not generate it.

What are Open Graph and Twitter tags?

They tell social platforms which title, description and image to show when your link is shared. Facebook and LinkedIn read Open Graph tags, and X (Twitter) reads its own twitter: tags and can fall back to Open Graph. Platforms often cache previews, so a change may not show straight away.

Where do I put the generated code?

Paste it inside the head section of your page. If your site or SEO plugin already adds some of these tags, avoid pasting the same tag twice. The tool lets you leave out the canonical and the charset and viewport tags.

What makes a password strong?

A strong password is long, random and used for only one account. Strength comes from how many possible passwords an attacker would have to try. Each extra character multiplies that number, which is why length matters more than clever substitutions such as turning an a into an @.

This tool picks every character at random, so the strength depends only on the length and the character types you choose.

How to use the password generator

  2. Tick the character types the website accepts.
  3. Press Generate if you want a different password. A new one is also made when you change an option.
  4. Copy it straight into your password manager or the sign-up form.

Good password habits

  • Use a different password for every account.
  • Store them in a password manager instead of memory or a note.
  • Turn on two-factor authentication.
  • Never share a password in a message, and check the address before you type it.

Frequently asked questions

Is it safe to use an online password generator?

This one creates the password in your browser, using the secure random generator built into the browser. The password is not sent anywhere and not saved. As a general habit, use generators whose behavior you can trust, and never share a generated password with anyone.

How long should my password be?

For important accounts such as email, banking and your password manager, use 16 characters or more. Longer is stronger. For less important accounts, 12 characters or more of random characters is a sensible minimum.

What does the strength meter measure?

It estimates entropy in bits from the length and the number of different characters in the set, assuming the password is random. It is accurate for passwords made by this tool, but it does not suit passwords you made up yourself, because people are not random.

Do I need symbols in my password?

Not always. Length matters more than symbols. Symbols add some strength, but some websites reject certain symbols. If a site refuses a password, untick Symbols and use a longer one.

What does Exclude similar characters do?

It removes characters that look alike, which are 0, O, o, 1, l and I. This helps when you have to read or type the password by hand.

Where should I keep my passwords?

Use a password manager, and use a different password for every account. Turn on two-factor authentication where it is available, because even a strong password can be stolen by a fake login page.

How does the tool make random passwords?

It uses the browser's secure random generator (crypto.getRandomValues), which is designed for security. The tool avoids the simple remainder method that favors some characters, and it makes sure every character type you ticked is present.

Is the password saved or sent anywhere?

No. It exists only on this page. Nothing is stored in your browser, and nothing is sent to Ruvixsa. When you close the page, the password is gone.

What is a QR code generator?
A QR code generator turns information, such as a web address, a WiFi login or a contact card, into a square code that a phone camera can scan. This tool makes the code in your browser, lets you add your logo and a color, and gives you a PNG to download.
The codes are static. The information is stored in the image itself, so they do not expire and nothing is tracked.


How to make a QR code
  1. Choose the type of QR code, such as a link, text, WiFi or contact card.
  2. Enter the details. The tool checks them and tells you if something is missing or wrong.
  3. Add a logo (optional) and pick a color.
  4. Press Generate. You will see the code and the exact text stored inside it.
  5. Download the 1024 px PNG and scan it with your phone before you use it.


QR code types you can create
  • URL / Link: opens a web page. If you leave out https://, the tool adds it.
  • Plain Text: shows any text.
  • WiFi: shares a network name and password.
  • WhatsApp: opens a chat with a number, with an optional first message.
  • Phone Number: starts a call.
  • Email: opens a new email with an optional subject and message.
  • SMS: opens a text message with an optional message.
  • vCard (Contact Card): lets people save your contact details.


Tips for QR codes that scan well
  • Use a dark color on the white background.
  • Keep the logo small and always test the finished code with a phone.
  • Keep the blank border around the code.
  • Shorter data makes a simpler code that is easier to scan.
  • Anyone who scans a code can read what is inside, so do not put secrets in it.


Frequently asked questions
Is this QR code generator free?
Yes. It is free to use, with no sign-up. The QR code is made in your browser and what you type is not uploaded to a server.
Do these QR codes expire?
No. The QR codes made here are static: the information is stored inside the image itself, so they do not expire and nothing is tracked. If you change your link later, you will need a new QR code, unless the link itself redirects.
Can I add my logo to the QR code?
Yes. Choose a PNG, JPG or SVG up to 2 MB. The logo is placed in the centre and covers about 20 percent of the width. The tool uses the highest error correction level to keep the code readable, but you should always scan it with your phone before printing.
What size is the downloaded file?
You get a PNG of 1024 by 1024 pixels, which is enough for most print and screen uses. The preview on the page is smaller.
Which colors scan best?
Dark colors on the white background scan best. Very light colors are hard for phone cameras to read, so the tool warns you when the color is too light.
How much text can a QR code hold?
About 2,300 letters of plain English text, and about 1,200 with a logo. Text in other languages uses more space, so the limit is lower. Shorter data makes a simpler code that is easier to scan.
Why does the WhatsApp QR code need a country code?
WhatsApp links use the full international number. A number such as 0300 1234567 will not work, so write it as +92 300 1234567. The tool tells you if the country code is missing.
Is it safe to put a WiFi password in a QR code?
Anyone who scans the code can read the password, so only share it with people you trust. The password is not sent to Ruvixsa; it stays in your browser.
